# Runtime dependencies for the Raspberry Pi 5 (ARM64, CPU only).
#
# Notably absent, and deliberately so:
#   torch / torchvision / ultralytics  -> inference runs on onnxruntime; these
#       are only needed once, off-device, to export the ONNX model.
#       See requirements.export.txt.
#   celery / redis                     -> the job queue is a SQLite table.
#   boto3 / minio                      -> storage is the local filesystem.
#   alembic                            -> schema is created with create_all.
#   psycopg2 / asyncpg                 -> the database is SQLite.
#
# This keeps the Pi image around 600 MB instead of ~3 GB and cuts worker
# start-up from ~25 s to ~3 s.
